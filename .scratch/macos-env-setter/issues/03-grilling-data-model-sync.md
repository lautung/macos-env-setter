Type: grilling
Status: open
Blocked by: 01, 02

## Question

敲定工具的数据模型与两层写入的同步语义（用 /grilling + /domain-modeling 与用户对谈后关票）。待决问题：

1. 一条变量记录的字段：key / value 之外，要不要记录「作用层」（shell / GUI / 两层）与来源（工具创建 / 导入）？
2. 编辑一条变量后两层怎么写：总是同时写，还是允许单层开关（比如某变量只想给 shell 用）？GUI 层写不进去时如何降级与提示？
3. 与手工编辑的冲突：~/.zprofile 标记块外的内容工具永不触碰（已定）；但标记块内若被用户手工改动，工具打开时怎么处理（以文件为准重新载入？提示冲突？）。
4. 导入：v1 是否提供「把 ~/.zprofile 标记块外已有的 export 一键收编」？收编后原行删除还是保留？
5. 备份与恢复：写入前自动备份的文件位置与保留策略，恢复入口放在哪。
