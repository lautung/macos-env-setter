# UI 原型（PROTOTYPE — 用完即弃）

wayfinder 票 #4「UI 原型走查」的走查件：主窗口三个**结构不同**的变体，回答四个 UI 问题。不是产品代码，无持久化，样例数据。

## 运行

```bash
./run.sh        # swift build + 组装 .app + 打开
```

切换变体：底部浮动条点 ‹ ›，或键盘 ← →（输入框获得焦点时不劫持）。

## 变体与四个问题的观察点

| 问题 | A · 侧栏 + 详情 | B · 密集表格 + 状态栏 | C · 状态看板 + 工具带 |
|---|---|---|---|
| 1. 主界面布局/搜索 | 侧栏列表 + 右侧详情表单，搜索在侧栏顶 | 单栏 Table 六列，工具行内搜索 | 按两层状态分组的卡片看板，顶栏搜索 |
| 2. PATH 专用 UI | 选中 PATH 行，详情区就地展开（拖拽 + ↑↓） | 「排列条目…」弹全宽编辑表 | 顶部固定 PATH 卡片（compact 行 + ↑↓） |
| 3. 两层状态/生效语义 | 行内 chip + 详情状态区；工具入口在侧栏「工具」区 | 表格圆点列 + **底部状态栏**放诊断入口 | 分组即状态；**顶部待生效横幅**最醒目 |
| 4. 备份/收编/打码 | 侧栏「工具」区入口 | 状态栏入口 | 底部工具带入口 |

生效语义（「只影响之后新启动的 App」）三个变体都在：应用按钮 help、应用后的横幅、编辑表单状态行、重启指定 App 弹窗里重复出现。秘密值打码：列表/表格里固定打码，编辑表单可临时显示（眼睛），变体 C 有全局显码开关。
